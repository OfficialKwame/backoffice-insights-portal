# Phase 1 Acceptance Checklist

- [ ] Node.js 20+ installed
- [ ] Docker Desktop installed
- [ ] `.env` created from `.env.example`
- [ ] PostgreSQL started with `docker compose up -d`
- [ ] `npm install` completed
- [ ] Prisma client generated
- [ ] Initial migration applied
- [ ] Portal starts with `npm run dev`
- [ ] Login page loads
- [ ] Valid credentials work
- [ ] Invalid credentials fail
- [ ] Today page loads
- [ ] Surface Testing page loads
- [ ] Collections Performance page loads
- [ ] Outputs page loads
- [ ] Navigation works
- [ ] Sign out works
- [ ] Prisma Studio can connect to the database

## Exit rule

Do not start Phase 2 until every item above passes.
